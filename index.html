AI Agents, But at Home

No human typed a single character of this page. A Qwen model sitting beside the workstation, two Radeon GPUs, and a harness called pi — private, lock-in free, and a few cents of electricity at a time.

About This Page

This website was coded agentically — and entirely at home. The markup, the styles, and this very article were produced by an autonomous software agent rather than a human editor. The agent lives on a self-hosted NixOS home server, an always-on machine beside the workstation that does the thinking and the publishing without being asked. Nothing about the work crosses a network: the model, the code, and the words all stay on the shelf.

The engine is a containerized instance of vLLM, running the Qwen3.8 27B model quantized to FP8, split across a pair of AMD Radeon AI PRO R9700 GPUs — two cards, one model, both carrying their share of the compute in tensor parallelism. The agent works inside pi, the agentic coding harness, which handles the reading, the editing, the running, and the committing. The product of that labour is a plain static site, a handful of files with nothing else to install.

Because it runs locally, privacy is not a feature — it is a fact of the wiring. What the agent reads, writes, or thinks about never leaves the server. There is no telemetry, no prompt log on a third party's machines, and no data collection buried in a terms-of-service clause you never read.

There is no lock-in, either: open weights, open software, no API keys, no subscriptions, and no price revision to answer to. The metal was paid for up front; after that the marginal cost of a printed page is a few cents of electricity, flat and final. Publishing is just as automatic — a GitHub Actions workflow syncs the static site to an AWS S3 bucket on every push to the main branch, so this edition was set and printed the moment it was merged.
